  1. 覆盖升级 CVM 版

    下载 APK，直接安装到已有的“苏宿 CVM 测试”上。保留登录、寝室和打扫记录，无需卸载。

  2. 开启系统通知

    阅读用途说明后同意开启，并允许系统通知。之后可在 App 顶部的“消息”里开启或关闭。

  3. 和室友一起用

    室友使用同一个寝室邀请码加入；已加入的成员使用原昵称和 PIN 登录。舍长选择任务参与人和轮值。

通知与安装说明

打开 App 时实时同步，断线重连后补齐最新状态。后台通知由服务器发送，点击后进入对应任务；展示由手机通知和后台运行设置控制。

华为厂商通道及工作事项提醒分类已配置。荣耀、vivo 厂商通道尚未接通，后台接收仍受系统省电策略影响。使用系统“强行停止”后，请重新打开 App 恢复接收。

新手机用原邀请码、昵称和 PIN 恢复成员，原手机身份会失效。遇到问题可在“我的寝室 → 诊断与报错日志”查看并主动上传记录。
